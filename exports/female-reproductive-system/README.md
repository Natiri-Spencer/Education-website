# Female Reproductive System — Grade 7

A five-minute, narrated 1920 × 1080 / 24 fps lesson for CBE STEM ACADEMY.

- Main video: `female-reproductive-system-grade7-5min.mp4`
- Audio: `narration.wav`
- Subtitles: `.vtt` and `.srt`
- Script: `transcript.txt`
- Scene timing: `chapters.json`
- Main artwork: `assets/female-reproductive-anatomy.png`
- Poster: `poster.png`
- Individual scene videos: `canva-scene-clips/` (13 MP4 clips)
- Image-generation prompt: `assets/visual-prompt.txt`

The illustration is anatomically styled; labels, highlighted structures and explanatory motion are editable in `tools/render_female_reproductive.cjs`. The narration script is in `tools/female_reproductive_story.json`. Narration was recorded with the installed Windows voice. The final video includes visible captions.

Canva handoff: upload the MP4 for a ready-to-play video. For a new edit, upload the artwork and narration WAV, use `chapters.json` for scene timing, and reproduce labels from the script. This export was produced locally and is ready to import into Canva; it is not an editable Canva design or a Canva-hosted project.
